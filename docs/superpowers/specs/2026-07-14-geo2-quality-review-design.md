## 1. 背景与目的

GEO2 是一个 GEO（搜索引擎优化）方向的 AI Agent 项目，已经走过 v0.1–v0.6 共 6 个版本迭代，并在近期完成三个内部 phase（Phase 1: Agent Loop 整合；Phase 2: Memory 向量化；Phase 3: Context Budget）。

当前 docs 目录处于清理状态，多份历史 handoff / manual verification / roadmap 文档被标记删除但尚未提交。用户希望：

1. **学习总结**：`D:\Agent\学习文档\helson\` 目录下的 3 份 Markdown + 9 份 PDF 文档，提炼成精炼版方法论文档
2. **锐评本项目**：以**面试官视角**对 GEO2 做 11 维度全套质量锐评
3. **附带改进计划**：锐评基础上生成按优先级排序的改进建议

产出全部沉淀在 `D:\GEO2\docs\review\` 下，作为 GEO2 项目下一阶段（v0.7+）的输入。

## 4. 评分尺度（0–5 分制）

| 分数 | 含义 | 触发条件（示例） |
| --- | --- | --- |
| 0 | 缺失 | 完全没有该维度能力 |
| 1 | 雏形 | 仅有意向/注释/未落地代码 |
| 2 | 基础 | 最简实现，但不健壮 |
| 3 | 达标 | 满足基本工程要求 |
| 4 | 良好 | 工程化、有测试、可解释 |
| 5 | 卓越 | 行业领先、有自动化机制 |

**总分计算**：11 维度 × 5 分 = 55 分满分。

**分级**：
- 45–55：A 级（行业领先，面试可讲深度）
- 35–44：B 级（工程扎实，能讲清大部分问题）
- 25–34：C 级（基础可用，关键维度待补）
- 15–24：D 级（雏形阶段，面试有风险）
- <15：E 级（不建议作为亮点项目）
